`dependencies.json` records every resolved NuGet package ID, exact version,
package SHA512, license expression/file/URL, source repository and homepage.
`third-party/` preserves each package nuspec and included license/notice files.
The same manifests and notices are included in the corresponding source archive.
These separately licensed dependencies are unmodified. Their individual terms
apply; the WolvenKit changes are GPLv3. NuGet project links are retained when a
package does not supply a repository URL. Microsoft's .NET Framework runtime
is a platform prerequisite and is not redistributed.

The DDS texconv program copied by the upstream Common project is excluded from
the bundled helper runtime; it is unrelated to resource inspection. Debug
symbols are excluded. Source archive contents retain the original upstream
repository, including its own third-party assets and notices.
